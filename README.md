# EPUB 工具箱（epub_tool）

零第三方依赖的 EPUB 图形化工具（Python 标准库 + tkinter）。v1.3 新增的「漫画→CBZ」是唯一
需要可选依赖（Pillow / pypdf / cryptography）的功能，其余功能保持零依赖。

## 功能

1. **目录 → 整本 EPUB**：目录内每个 txt/md 文件作为一章（按文件名排序），整体打包；
   可选封面图片（界面内预览、打包时整页嵌入）；勾选「子目录作为卷」时，每个子文件夹是一卷。
2. **单文件 → 切割 → EPUB**：把单个文本按切割方式切分章节后打包（同样支持封面与元数据）。切割方式下拉可选，注册表式扩展：
   - 整行 12 个横线分隔（`------------`，大明测字天师式）
   - 章节标题正则（`第X章`）
   - 卷/章两级（`第X卷` + `第X章`，生成两级目录）
   - 固定行数切分
   - LLM 智能切割（预留扩展口，见 `epub_tool.py` 中 `split_by_llm`）
3. **EPUB 追加章节**：指定 epub + 若干 txt（每个 txt 一章），解包 → 末尾追加 → 重打包；
   选中 epub 后自动检测**是否已有封面**并就地预览，也可在此直接换封面（原封面默认保留）。
4. **封面管理**：界面内预览封面（不依赖系统看图器）、另存为图片（默认存到程序目录下的
   `封面导出/`）、用系统看图器打开、替换/设置封面（输出新文件）。
5. **EPUB → TXT 拆解**（追加流程解包环节的逆功能）：把 epub 拆解为可再次合包的 txt——
   - 单个 txt：章节间用整行 12 横线分隔，可被功能 2 的"横线分隔"切割原样还原
   - 每章一个 txt 到目录：首行为章节标题，可被功能 1 / 3 直接识别
6. **漫画 → CBZ**（v1.3，可选依赖）：两类输入、一个出口——
   - **单行本 PDF**：每卷一个 CBZ，双页跨页**原样保留**（拆不拆交给阅读器），
     首图若是「封底｜书脊｜封面」三段展开，自动裁出正面作第 1 页
   - **条漫 / 散图目录**：下载器拼出来的超长图按白带切回原始分镜，每话一个 CBZ
   - 生成 `ComicInfo.xml`（Series / Number / PageCount / `Manga`），Komga、KMReader 直接识别

   **分组规则**（按目录判定，决定「哪些文件合成一本」）：

   | 目录里有什么 | 结果 |
   | --- | --- |
   | `001_01` `001_02` `002_01` | 按第一段分话：第001话(2页) + 第002话(1页) |
   | `a_01` `a_02` `b_01` | 字母前缀同样当话号：a 一话 + b 一话 |
   | `z_01` … `z_20` | 一话，话号 `z`，页序按数字（z_02 在 z_10 前） |
   | `001` `002` … `030` | **整个目录一话**——这些是页号，不是话号 |
   | 无编号（`cover.jpg` 等） | 整个目录一话，话号取目录名；`第12话/` → 第012话 |

   目录里混用「话_页」和单编号命名时，单编号文件归到目录那一话，并在日志里提示。

**可选依赖**：功能 6 需要 `Pillow`、`pypdf`、`cryptography`
（`py -3 -m pip install pillow pypdf cryptography`），其余功能仍然零第三方依赖。
缺库时该标签页自动禁用并给出安装提示，不影响其他功能。

**书籍元数据**：功能 1 / 2 都有「元数据...」按钮，可填作者、系列与序号、出版日期、出版社、
版权、简介，写入 `dc:*` 与 `calibre:series`，Kavita / Calibre 能正确分组显示。

**书内目录页**：默认在 spine 里生成一个可见目录页（`book-toc.xhtml`，支持两级），
不认 `nav.xhtml` 的阅读器也能翻到目录；可在界面上关掉。

界面：标签页选中项为蓝底白字，当前页一眼可辨；封面预览用 Windows 自带 GDI+ 渲染
（jpg/png/gif/bmp/tif/webp 均可），仍然零第三方依赖。

编码：自动识别 utf-8 / utf-16 / gbk / gb18030 / big5（含 BOM 与文件头 charset 声明）。

## 运行

- 双击 `启动工具.bat`（需 python.org 官方 Python 3，自带 tkinter）
- 或命令行：`python epub_tool.py`
- 自检：`python epub_tool.py --selftest`（端到端冒烟，验证五个功能 + 封面保留/替换）
- 回归测试：`python -m unittest discover -s tests -v`

## 测试

- `tests/test_regressions.py`（48 项）：覆盖切分（含前导内容 / 分卷）、EPUB→TXT（含小标题 / GBK 编码）、
  追加章节（含多级目录）、章节顺序解析、封面识别与嵌入、元数据、书内目录页、临时目录清理等场景。
- `tests/test_comic.py`（16 项）：功能 6 的命名解析、话号合并、自然排序、白带切分、CBZ 结构与
  ComicInfo、PDF 跨页保留与封面裁切。缺 Pillow / pypdf 时自动跳过，不影响其余测试。
- 测试产物写在 `.testtmp/`（已加入 `.gitignore`），可用环境变量 `EPUBTOOL_TEST_TMP` 改位置。
- 全部基于标准库 `unittest`，运行时依旧零第三方依赖。

## 变更记录

### v1.3（当前版本）

**新增功能 6：漫画 → CBZ**（可选依赖 Pillow / pypdf / cryptography）

1. **单行本 PDF → CBZ**：每卷一本；双页跨页**默认保留**（阅读器可自行拆分），
   首图若是「封底｜书脊｜封面」三段展开，裁出正面作第 1 页——否则 Komga 的缩略图会取到封底。
2. **条漫 / 散图 → CBZ**：按白带切分——下载器常把多张原图用几百像素的白带粘成一张超长图
   （实测样本 960×16667，其中 26.4% 是纯白），切回原始分镜后一页一个镜头。
3. **命名即分组**：`001_01.jpg` → 第001话（多段按段号合并）；`001.jpg` → 第001话；
   无编号时用目录名当话号。排序按数字大小，第2话排在第10话之前。
4. **ComicInfo**：写 Series / Number / Volume / PageCount / `Manga`，条漫写 `Manga=No`，
   PDF 单行本写 `YesAndRightToLeft`。
5. **内存友好**：边转换边写 zip，不再把整本 CBZ 攒在内存里。

> 白带检测只用 Pillow：先把像素二值化，再把宽度压成 1 像素取 BOX 均值——
> 一行里只要有一个暗点，均值就小于 255。与逐像素扫描结果完全一致，速度快两个数量级，
> 因此**没有引入 numpy**。

### v1.2

**正确性修复**（均附带回归用例）：

1. **切分保留前导内容**：首个 `------------` 或首个 `第X章` 之前的内容（内容简介 / 前言 /
   作者的话）现在作为「前言」一章保留，不再被静默丢弃。
2. **EPUB→TXT 保留小标题**：章节标题固定占 `h1`，正文小标题从 `h2` 起（h2 → `# 标题`、
   h3 → `## 标题`…），导出与重新打包的层级一致；不再被并进章节名后从正文里消失。
3. **多级目录追加不再错位**：nav 为嵌套 `<ol>` 时，新章节插入到最外层列表末尾
   （旧实现会插进别人的子目录）。
4. **不再漏章**：章节顺序解析改为 nav → ncx → spine → 包内其余正文页 逐级合并补齐，
   nav 只匹配到一部分也不会整份丢弃。
5. **封面识别与属性顺序无关**：改用标签属性解析；替换封面时保留 item 的其它 `properties`。
6. **编码自适应**：BOM → 文件头 `encoding`/`charset` 声明 → utf-8 → gb18030 → big5；
   GBK 编码的老书不再导出乱码，opf/nav/ncx 读入后按原编码写回。
7. **临时目录清理**：`build_epub` 失败时不再残留 `.epub_build_*` 目录。
8. `epub_ops.py` 同步修复第 1 / 3 / 6 条，保证 GUI 与 CLI 行为一致。

**界面与封面**：

1. **标签页高亮**：选中页改为蓝底白字加粗，当前在哪一页一眼可辨（改用 clam 主题以便自定义配色）。
2. **功能 1 / 2 支持封面**：新增封面行，可在界面内预览所选图片，打包时作为整页封面嵌入
   （`manifest` 的 `cover-image`、`<meta name="cover">`、`cover.xhtml` 三处同步）。
3. **功能 3 自动识别封面**：选定 epub 后立即检测并预览当前封面，显示「有封面 / 无封面」；
   可直接选图替换，追加打包时一并写入。
4. **功能 4 界面内预览 + 保存**：预览不再调用系统看图器；新增「保存封面...」，
   默认保存到程序目录下的 `封面导出/`，文件名 `<书名>_封面.<原扩展名>`。
5. **零依赖预览**：用 Windows 自带 GDI+ 生成缩略图后交给 Tk 渲染，支持 jpg/png/gif/bmp/tif；
   GDI+ 不认的格式（如 WebP）再用系统 WIC 兜底解码，仍然不需要 Pillow。
6. **WebP 封面自动转 PNG**：EPUB3 核心图片格式不含 WebP，嵌入时若源封面是 WebP 会转成 PNG，
   避免生成阅读器打不开的封面。
7. 窗口尺寸改为按屏幕自适应并在启动后最大化，小屏不再被裁切。

**结构与元数据**：

1. **元数据**：新增「元数据...」对话框，可填作者、系列（含序号）、出版日期、出版社、版权、简介；
   写成 `dc:creator / dc:date / dc:rights / dc:description` 与 `calibre:series(+_index)`，
   Kavita / Calibre 能正确显示作者并按系列分组。
2. **卷 / 章两级结构**：章节可以带卷名，会生成卷首页 `vol_00N.xhtml`，nav 与 NCX 变成两级嵌套目录
   （`dtb:depth=2`）。两种来源：
   - 功能 1：勾选「子目录作为卷」，每个子文件夹算一卷；
   - 功能 2：新增切割方式「卷/章两级（第X卷 + 第X章）」。
3. **书内目录页**：新增 `book-toc.xhtml` 并放进 spine（`linear="yes"`），不认 nav 的阅读器也能看到目录；
   界面上的「生成书内目录页」开关可以关掉。
4. **封面不占阅读顺序**：spine 改为 `<itemref idref="cover" linear="no"/>`。
5. **`<guide>`**：补上 cover / toc / text 三个 reference，兼容 EPUB2 阅读器定位。
6. **排版细节**：CSS 增加 `@page { margin: 0 }`、`orphans/widows: 2`、末段去下边距、卷页与目录样式。

## 已知限制（下一阶段计划）

- 切分/打包逻辑在 `epub_tool.py`、`epub_ops.py`、`build_epub.py` 各有一份，计划抽取为共享核心
  模块（`epubkit/`），并删除硬编码的 `build_epub.py`。
- OPF / NAV / NCX 仍是正则编辑，计划改为结构化解析（ElementTree）。
- GUI 暂不支持进度条、取消、拖拽；固定行数切分会把每块首行当作标题。
- 正文只支持纯文本：插图、脚注、ruby 注音、内嵌字体尚未支持（参考 `ANALYSIS.md` 的 P2/P3）。
- 暂不提供 EPUB2 兼容输出模式（只输出 EPUB3 + NCX 双目录）。

## 打包 exe

双击 `build_exe.bat`，或手动执行：

```
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --onefile --windowed --name epub_tool --clean epub_tool.py
```

产物：`dist\epub_tool.exe`（免安装 Python 双击即用）。

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `epub_tool.py` | 主程序（GUI + 核心逻辑 + 切割注册表 + 封面处理） |

| `build_exe.bat` | exe 打包脚本 |
